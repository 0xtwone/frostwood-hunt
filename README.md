# 霜林猎歌 Frostwood Hunt

单文件 HTML / three.js 的第三人称北境猎魔小游戏。原创角色与世界：霜誓猎人艾芮娅、战马「雪雀」、灰木村与「醉鸦」酒馆、云杉林中的霜狼、湖沼泥尸与石环里的林魇。

## 运行

直接用浏览器打开 `index.html`（需要联网加载 three.js r128 CDN）。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 行走（Shift 奔跑） |
| 鼠标拖动 / ← → | 转动视角（滚轮缩放） |
| 空格 / J | 挥刃攻击 |
| E | 交谈 · 进出酒馆 · 喝酒 |
| F | 上马 / 下马 |
| H | 吹口哨唤马 |
| M | 音乐开关 |

地形、贴图、模型与配乐全部由代码程序化生成，没有外部美术或音频资源。
